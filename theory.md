# Теоретичні питання про масиви

## Що таке масив?
Масив — це впорядкована сукупність однотипних елементів даних, що зберігаються у суміжних комірках пам'яті й доступ до яких здійснюється за індексом. Масив дозволяє ефективно працювати з великою кількістю значень одного типу, виконуючи групові операції над ними.

## Який індекс має 5-й по порядку елемент лінійного масиву?
У більшості мов програмування індексація масиву починається з нуля, тому п'ятий за порядком елемент має індекс 4. Якщо ж мова використовує іншу систему індексації, відповідь слід адаптувати, але для стандартної нульової індексації відповідь — 4.

## Як можна визначити розмір масиву?
Розмір масиву можна визначити:
- зберігаючи кількість елементів у додатковій змінній під час ініціалізації;
- використовуючи вбудовані засоби мови, наприклад `len(array)` у Python, `array.length` у Java або властивість `size()` у контейнерів C++ STL;
- підраховуючи елементи під час обходу масиву, якщо інших способів немає.

## Якого типу можуть бути елементи масиву?
Елементи масиву можуть бути будь-якого одного типу, підтримуваного мовою програмування: числового (цілі, дійсні), символьного, логічного, рядкового, об'єктного, а також складених типів (структур, записів, класів). Головне обмеження — всі елементи одного масиву мають бути однотипними.
